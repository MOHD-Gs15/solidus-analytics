fix(analytics): MySQL-era ledger verification + dashboard data integrity (2.1.3)

Closes the DB_SCALING_PLAN §8.5 item (re-verify Analytics against a
MySQL-backed ledger) and fixes the reported "insane chart inflation".

Volume accounting (the inflation root cause):
- Exclude escrow churn (BID_PLACED / BID_REFUNDED) and receiver-side
  mirrors (TRADE_RECEIVE, AUCTION_SOLD, DEATH_REWARD) from volume.
- AUCTION_WON counts only when it is a real settlement (target_uuid
  set), never the /ah collect item-delivery artifact.
- Worked example: a 1200 S$ bid-settled auction reported 6800 S$
  (5.7x); a 50-bid war reported ~100x. Now exactly the real sale.

DB_SCALING_PLAN §8.5 (MySQL-backed ledger):
- New CoreLedgerAccess: when Core runs MySQL network mode
  (EconomyEngine.isMysqlMode() via reflection), every collector
  (LiveMetricsTracker, SnapshotScheduler, WealthDistributionProvider,
  InflationCalculator) reads through Core's own
  TransactionLog.withConnection(SqlWork proxy) connection -
  backend-agnostic, zero new production dependencies. Previously ALL
  collectors read SQLite files and silently died in MySQL mode.
- CoreLedgerAccessMySqlTest (CI-gated, real mariadb:11 service in the
  workflow) proves the SQL portability + DECIMAL(18,2) cents contract;
  PASSED against real MariaDB 11.8.6 locally.

Memory-leak / double-count hardening:
- The infinite polling loop used to occupy the shared single-thread
  AnalyticsDatabase worker, starving every queued task (snapshot
  inserts, daily upserts, dashboard publishes, cleanup) and growing
  the queue without bound - a genuine memory leak. The poller now has
  a dedicated daemon thread.
- start()/stop() are serialized (the old check-then-act guard could
  spawn two polling loops feeding the same counters) and stop() joins
  the thread before persisting.
- Two-phase poll: rows are buffered before any counter is applied, so
  a failed read can never double-count; 20k row cap per cycle.

Dashboard (web):
- app.js: the volume trend chip divided the cents delta by 100 twice
  and displayed 1/100 of the real day-over-day delta.
- style.css: chart container hardening - pinned geometry + max-height
  safety valve for the aspect-locked SVG (no canvas/Chart.js is used;
  the SVG is rebuilt via replaceChildren() on every poll, so there is
  no DOM/listener accumulation to leak).

Tests: bid-war volume regression, lifecycle idempotency, SQLite seam
suite for CoreLedgerAccess; full suite 84 executions / 0 failures
(1 gated skip locally, active in CI).
